      ```python
      from llama_cloud import LlamaCloud
      from llama_index.core import Document, VectorStoreIndex

      client = LlamaCloud()  # reads LLAMA_CLOUD_API_KEY

      file = client.files.create(file="data/report.pdf", purpose="parse")
      result = client.parsing.parse(
          file_id=file.id, tier="agentic", version="latest", expand=["markdown"]
      )
      pages = result.markdown.pages
      documents = [Document(text=p.markdown) for p in pages if p.success]

      index = VectorStoreIndex.from_documents(documents)
      query_engine = index.as_query_engine()
      response = query_engine.query("What does this document say about pricing?")
      print(response)
      ```

Put a few files in a folder called `data` first. The OpenAI route needs an [OpenAI API key](https://platform.openai.com/api-keys), the local route needs [Ollama](https://ollama.com/) and no key, and the LlamaParse route needs a [LlamaParse API key](https://cloud.llamaindex.ai/?utm_source=developers&utm_medium=docs&utm_campaign=framework-landing&utm_content=quickstart) and handles scans, tables and forms. Longer versions: the [starter tutorial](/python/framework/getting_started/starter_example/), the [local-models tutorial](/python/framework/getting_started/starter_example_local/), and [how to read these docs](/python/framework/getting_started/reading/).

## When the documents get hard

Built-in readers are fine for clean text. For scanned PDFs, forms, spreadsheets and slide decks, the quality of what goes into your index decides the quality of every answer. That is what [LlamaParse](/llamaparse/) is for: [Parse](/llamaparse/parse/), [Extract](/llamaparse/extract/), [Classify](/llamaparse/classify/), [Split](/llamaparse/split/) and [Index](/llamaparse/cloud-index-v2/getting_started/), as in the third tab above. For fully managed retrieval, [Index](/llamaparse/cloud-index-v2/getting_started/) keeps an index in sync with your data sources and serves retrieval to your query engine or agent.

## How the pieces fit together

LLMs are trained on public data, not yours. LlamaIndex makes your data available to the model at the moment it answers, a pattern called context augmentation, of which [RAG](/python/framework/getting_started/concepts/) is the best-known form. The framework is a set of composable parts for that job; the high-level API gets you from documents to answers in five lines, and the lower-level API lets you replace any part when the defaults stop being enough.
